# Roadmap

This roadmap records future development direction for Living Aegis Origin. Items listed here should be implemented in small, separate steps.

## Initial Foundation

- [x] Create static project structure.
- [x] Add GitHub Pages-compatible `index.html`.
- [x] Add basic Canvas 2D initialization.
- [x] Add documentation files for project tracking.

## Future Steps

- [ ] Confirm GitHub Pages deployment.
- [ ] Expand the Canvas 2D base screen after scaffold review.
- [ ] Add a minimal HUD.
- [ ] Add aiming behavior.
- [ ] Add firing behavior.
- [ ] Add missile behavior.
- [ ] Add visual effects in a controlled pass.
- [ ] Add sound effects and audio handling.

Gameplay systems, combat, input handling, animation systems, scoring, and complex HUD work are outside the initial scaffold.
